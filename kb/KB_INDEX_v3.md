## 🎓 Learning Paths

### Path 1: Complete Beginner to NPC Developer (4-6 weeks)

**Week 1-2**: Basics
- Read: KB_REF_FAQ.md
- Read: KB_REF_Constants.md
- Practice: KB_REF_NPCExamples.md (copy and modify examples)

**Week 3-4**: Core Scripting
- Study: KB_REF_ScriptCommands.md (focus on 50 most common commands)
- Practice: Create 5+ simple NPCs (shops, warpers, buffers)

**Week 5-6**: Intermediate Development
- Study: KB_REF_QuestSystem.md
- Study: KB_REF_ItemGroups.md
- Practice: Create complete quest with rewards

**Graduation Project**: Build a complete NPC system (e.g., donation system, minigame, event)

### Path 2: Database Specialist (2-3 weeks)

**Week 1**: Fundamentals
- Study: KB_REF_DatabaseStructure.md (complete)
- Practice: Create 10 custom items, 5 custom monsters

**Week 2**: Advanced Content
- Study: KB_REF_ItemBonuses.md (200+ bonuses)
- Study: KB_REF_MobModesAI.md (monster behavior)
- Study: KB_REF_SkillSystem.md
- Practice: Create item set with bonuses, boss monster with AI

**Week 3**: Integration
- Study: KB_REF_ItemGroups.md (reward systems)
- Practice: Create complete content pack (items, monsters, drops, boxes)

### Path 3: Advanced System Developer (6-8 weeks)

**Weeks 1-2**: Prerequisites (Complete Path 1)

**Weeks 3-4**: Advanced Scripting
- Study: KB_REF_ScriptCommandsExpanded.md (120+ commands)
- Study: KB_REF_AdvancedScripting.md (optimization, SQL)
- Practice: Implement dynamic shop, SQL-backed system

**Weeks 5-6**: Complex Systems
- Study: KB_REF_InstanceSystem.md (memorial dungeons)
- Practice: Create complete instance dungeon

**Weeks 7-8**: Optimization & Production
- Practice: Optimize existing systems with freeloop, SQL batching
- Study: Production deployment patterns
- Project: Build scalable event system
